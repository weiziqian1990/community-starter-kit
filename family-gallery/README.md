# 家庭历史展览馆 📸

一个现代化的家庭照片展览馆应用，可以批量导入照片，自动按时间线组织，并使用 AI 生成温馨的家庭故事。

## ✨ 主要功能

- **📤 批量照片上传**：支持拖拽上传多张照片
- **📅 智能时间线**：自动提取照片 EXIF 数据，按时间排序和分组
- **🤖 AI 故事生成**：使用 Claude AI 分析照片并生成温馨的家庭故事
- **🎨 精美界面**：现代化的渐变设计和流畅的动画效果
- **📍 位置信息**：显示照片的地理位置（如果有）
- **📷 设备信息**：显示拍摄设备信息

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

应用将在 http://localhost:5173 启动

### 构建生产版本

```bash
npm run build
```

## 🔑 配置 API Key

1. 访问 [Anthropic Console](https://console.anthropic.com/)
2. 创建一个 API Key
3. 在应用中点击右上角的设置按钮（齿轮图标）
4. 输入你的 API Key 并保存

## 📖 使用方法

1. **上传照片**
   - 点击上传区域选择照片，或直接拖拽照片到上传区域
   - 支持批量上传多张照片
   - 应用会自动提取照片的 EXIF 数据（拍摄时间、地点、设备等）

2. **查看时间线**
   - 照片会按年份和月份自动分组
   - 时间线从最近到最早排列
   - 每组最多显示 6 张照片缩略图

3. **生成 AI 故事**
   - 点击"生成这段时期的故事"按钮
   - AI 会分析照片的时间、地点等信息
   - 自动生成一段温馨的家庭故事

## 🛠️ 技术栈

- **React 18** - UI 框架
- **TypeScript** - 类型安全
- **Vite** - 快速构建工具
- **Tailwind CSS** - 样式框架
- **exifr** - EXIF 数据提取
- **@anthropic-ai/sdk** - Claude AI 集成
- **lucide-react** - 图标库

## 📝 注意事项

- API Key 存储在浏览器的 localStorage 中
- 照片仅在浏览器中处理，不会上传到服务器
- 建议使用现代浏览器（Chrome、Firefox、Safari、Edge）
- 照片文件应包含 EXIF 数据以获得最佳体验
